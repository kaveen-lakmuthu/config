## Tags (managed by the Windows page)

- `Super+1…N`: show tag
- `Super+Shift+1…N`: move window to tag
- `Super+Control+1…N`: toggle displayed tag
- `Super+Shift+Control+1…N`: toggle the window on a tag
- `Super+0`: show all configured tags
- `Super+Shift+0`: put the window on all configured tags
